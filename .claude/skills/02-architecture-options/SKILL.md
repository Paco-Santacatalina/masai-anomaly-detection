# Architecture Options

## Purpose
Design before building and expose meaningful trade-offs.

## Procedure
1. Read approved specification.
2. Inspect current architecture.
3. Identify constraints.
4. Produce 2-3 materially different options when non-trivial.
5. For each cover structure, data flow, deployment, dependencies, failure modes, security, testability, scalability, operations, migration and reversibility.
6. Compare options.
7. Recommend one without silently selecting it.
8. Record human decision as ADR.
