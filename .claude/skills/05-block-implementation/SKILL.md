# Block Implementation

Implement one approved block using scoped context.

Preconditions: feature, specification, architecture and block exist.

Procedure:
1. Read Context Pack.
2. Inspect existing implementation.
3. Reuse sound patterns.
4. Implement smallest coherent change.
5. Add tests.
6. Execute tests.
7. Inspect diff.
8. Check requirement coverage.
9. Update status.
10. Produce review summary.

No unrelated refactoring, silent architecture changes or invented APIs.
