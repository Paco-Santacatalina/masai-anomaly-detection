# Testing

Verify behavior with evidence.

Preferred layers:
1. unit
2. integration
3. API/contract
4. database
5. component
6. end-to-end
7. AI/agent evaluation

Map important FR/AC to tests. Include null, empty, malformed, invalid type, boundaries, duplicates, missing dependencies, timeout, partial failure and external API changes where applicable.

For agents evaluate tool choice, arguments, permissions, guardrails, prompt injection, recovery, deterministic rules, quality, cost and latency.

Record exact commands and actual results.
