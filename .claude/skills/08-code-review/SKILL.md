# Code Review

Review:
- correctness
- robustness with unexpected data
- responsibilities and coupling
- maintainability
- tests
- performance
- observability
- consistency with architecture

Ask: Could another engineer explain and safely modify this code?

Focus on actionable findings rather than praise.
