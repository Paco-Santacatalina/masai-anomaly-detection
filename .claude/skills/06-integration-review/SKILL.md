# Integration Review

Review how completed blocks behave together.

Check contracts, data transformations, error propagation, transactions/consistency, async behavior, timeouts/retries, observability, API compatibility, frontend/backend alignment, agent/tool boundaries and regressions.

Findings: BLOCKER, HIGH, MEDIUM, LOW, NOTE. Every finding needs evidence and location.
