# Frontend React

Read functional requirements and API contracts. Inspect existing components. Define boundaries. Handle loading, empty, error and success states. Validate input. Consider accessibility. Add behavior tests.

Do not invent API fields or duplicate domain rules unnecessarily. Avoid giant components and follow project patterns.
