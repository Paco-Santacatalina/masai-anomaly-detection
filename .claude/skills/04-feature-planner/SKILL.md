# Feature Planner

Break a designed feature into manageable implementation blocks.

Each block must contain:
- purpose
- requirements covered
- dependencies
- inputs
- outputs
- files/components
- risks
- tests
- acceptance conditions

Avoid giant blocks, unrelated domains and hidden architecture decisions.
