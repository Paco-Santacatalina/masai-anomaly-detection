# Architecture Review

Challenge the selected architecture before implementation.

Check requirements coverage, boundaries, responsibilities, external dependency isolation, data ownership, failure modes, security, observability, complexity and evolution.

Block when critical requirements have no architectural path, security boundaries are undefined, data ownership is ambiguous, or irreversible decisions are unexplained.

Output strengths, weaknesses, risks, missing decisions, recommended changes and approval/blocking status.
