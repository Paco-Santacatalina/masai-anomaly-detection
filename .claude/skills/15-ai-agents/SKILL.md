# AI / ML / Agents

Document every meaningful agent's goal, inputs, outputs, instructions, tools, permissions, state, memory, failure modes, escalation, evaluation, observability and cost/latency constraints.

Tools require explicit schema, validation, authorization, bounded side effects and useful errors.

Separate reasoning, planning, tool execution, state transitions and irreversible actions. Irreversible actions require explicit authorization/guardrails.

For ML document dataset, preprocessing, training, evaluation, metrics, model version, reproducibility and monitoring where applicable.

Successful examples are not evidence of reliability; reliability requires defined evaluation and measured results.
